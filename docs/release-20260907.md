# xlh 20260907 发布说明

包含本轮全部功能：沪深/美股/港股分类、历史趋势图、5/20 日预测首次留档与到期核验、收益标签修复审计、采集行情默认永久保留。历史回放和真实预测表现分开展示，复权未确认的记录不进入正式命中率。

## 发布包

- `xlh-linux-x86_64-release-20260907.tar.gz`：Linux x86_64 二进制、配置示例、文档及备份脚本。
- `xlh-image-linux-amd64-20260907.tar.gz`：Docker 镜像导出文件，直接用于 `docker load`。
- `xlh-deploy-20260907.zip`：Docker 部署配置示例和说明。

每个文件提供 SHA-256 校验文件。二进制运行环境以 Debian 12 为基准，需要 glibc、fontconfig、freetype；镜像已包含运行依赖。包内不包含用户数据库、历史行情、备份、会话、API 密钥或推送配置。

## 升级现有 Docker 服务

沿用现有 `.env` 中的状态目录，不要换成一个空目录。保留现有 `data`、`cache`、`output` 及全部备份。

1. 升级前使用 SQLite `.backup` 备份 `xlh.db`、`realtime.db` 和已存在的 `forecast.db`。可在安装有 sqlite3 的服务器执行：

   ```bash
   XLH_STATE_DIR=/实际状态目录 bash backup-all-data.sh
   ```

2. 检查镜像包的 SHA-256 后导入：

   ```bash
   sha256sum -c xlh-image-linux-amd64-20260907.tar.gz.sha256
   docker load -i xlh-image-linux-amd64-20260907.tar.gz
   ```

3. 保留现有配置，只将 `[realtime] retain_days` 改为 `0`，保留原 `db_path`；在现有 `.env` 中将 `XLH_IMAGE` 改为 `xlh:20260907`。不要直接覆盖现有配置为样例。`forecast.db` 将自动创建在 realtime.db 同目录。

4. 在原部署目录更新服务（原来没有 push 服务则不加 profile）：

   ```bash
   docker compose -f docker-compose.prod.yml --profile push up -d --force-recreate
   docker compose -f docker-compose.prod.yml --profile push ps
   docker logs --tail 50 xlh-web
   curl --fail http://127.0.0.1:8080/healthz
   ```

验证原账号、市场切换、趋势图和“实际预测跟踪”。到期结果需要等真实未来行情，初次升级没有命中率是正常现象。Web 运行时每 6 小时核验待验证预测。

## 二进制方式

将二进制包解压到新的版本目录。备份数据库并停止旧服务后，仅替换运行程序；沿用原工作目录与原配置，调整 `retain_days = 0`，然后重启。已有服务的 `.cache` 路径由原工作目录决定。

全新安装可复制 `config.example.toml` 为 `config.toml`，安装系统运行库后运行 `./xlh serve`。初始化管理员按 `./xlh admin --help` 操作，包中不内置账号密码。

## 回滚与限制

记录并保留升级前的镜像标签和配置副本。回滚程序时也恢复旧配置中的 `retain_days`，因为旧版不支持 `0`；先暂停旧版采集守护，避免重新开启其历史清理行为。不要删除新版新增的预测表或审计表。生产数据仍应永久保留。

本次修复过的采集数据库只是本地工作副本，未放进发布包、未覆盖生产数据库。服务器地址未指定时，本次交付仅为可下载发布包，不代表线上已经更新。
