# 实际预测跟踪与收益标签修复

## 已实现的行为

股票诊断生成 5/20 日预测后，将实际生成时间（UTC）、行情起点、完整输入价格、预测输出、模型版本、首次概率及当时历史上涨频率基准写入 `forecast.db`。该文件位于 `[realtime].db_path` 同目录，与原行情库分离，所有记录永久保留。

同一市场代码、行情日期、模型版本只登记一次；刷新不修改旧概率，也不会把旧历史回放补登记成过去实际发布的预测。带市场过滤和无过滤使用不同模型版本标识。修改评分规则或参数时必须更新 `MODEL_VERSION`，以免混合统计。

为了避免把当日未完成 K 线作为收盘，预测保守地只使用日期早于当前 UTC 日的日线；这会延迟部分市场的最新行情展示。到期按行情起点之后第 5/20 条可用日线判断，最新未结束日期不参与核验。交易所日历、停牌和数据缺口尚未单独核对，因此该期限是采集交易记录口径。

验证触发：

- 再次打开该股票诊断时。
- 手动或已有同步流程更新该股票行情时。
- Web 服务运行期间，启动时以及随后每 6 小时，后台抓取所有待验证股票并核验；该任务不发送消息、不交易、不生成额外预测。联网失败保持待验证并记日志。

后台抓取的核验价格批次完整保存在 `forecast_price_batches`。已结算记录不会被日后行情覆盖；起点和输入价格修订会排除尚未结算的相关预测，以免混合不同复权尺度。已结算指标不代表对随后所有数据修订都已复审。

## 页面指标

按本股、模型版本、5/20 日分别展示最近 180 个自然日登记记录的：已核验、待到期、暂定、排除数量；方向命中率；历史频率基准命中率；恒预测上涨命中率；模型/历史频率基准 Brier 概率误差；概率分箱的平均预测与实际上涨比例；最近 20 条首次预测记录。

历史频率基准仅使用登记时已经知道的同期限历史收益，和模型在完全相同的验证样本上比较。零收益属于“未上涨”。Brier 越低越好，固定 50% 概率的 Brier 为 0.25。概率分箱用于检查校准，并没有把现有规则概率自动变成经过校准的新概率。

没有合格到期样本时显示未知，不能显示 0% 或虚构命中率。少于 30 个不同起点日期提示证据不足；30 是展示提示阈值，不是达到后就证明有效。相邻预测的收益期限重叠，样本仍相关。复权未确认的股票（包括当前源下部分美股）只保存暂定结果，不计入正式指标。分组和排除会改变样本构成，因此不能把正式样本表现当作全部股票的表现。

## 收益标签修复

`realtime` 收盘汇总不再用另一条日线缓存替代原始快照收盘。现在使用库内 15:00–15:05:59 的最后一条价格，重算“触发原价到目标收盘附近原价”的价格变化；收盘、T+1、T+5 的修正写入 `signal_outcome_audit`，保存旧值、新值、触发价、目标价格、目标时间和方法版本，再更新相应字段。

次日和第五日按库中已采集市场日期计数，目标股票缺失、信号起点缺失、缺少收盘附近快照时不猜测结果，旧值或 NULL 保持原状。旧值保持不代表其已通过核验，必须以审计记录及数据覆盖范围区分。原价变化未调整分红、拆股，不能视为含分红投资收益，也不能直接与复权预测验证指标混用。

手动执行（建议在完整备份后的工作副本上）：

```powershell

```
